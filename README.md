# 黑8大师

一款为手机横屏设计的单机黑八台球 PWA。打开网页即可游玩，也可以添加到手机主屏幕并在首次加载后离线运行。

## 玩法

- 在球桌上滑动手指调整球杆方向。
- 使用右侧力度条控制击球力度，点击“击球”确认。
- 首次合法进球后分配全色球或花色球；清空自己的球组后再打进黑 8 即可获胜。
- 母球落袋、未碰到目标球或先碰错球组会判犯规，对手获得自由球。
- 玩家获得自由球时，点击球桌上的合法位置即可移动母球。

## 功能

- Matter.js 球体碰撞、库边反弹、摩擦减速和六袋检测
- 简化黑八规则、完整回合状态和胜负判定
- 简单、普通、困难三档电脑对手
- 三套球桌、球杆与环境主题
- 可调瞄准线、力度灵敏度、音效和震动
- 横屏安全区适配、离线缓存与可安装 PWA

## 本地开发

需要 Node.js 22+ 和 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址，并将手机旋转到横屏。

## 验证

```bash
pnpm test
pnpm build
```

测试覆盖规则判罚、AI 合法目标选择、碰撞、摩擦、库边反射和落袋判断。

## 发布

仓库的 `main` 分支每次推送都会运行测试和生产构建。全部通过后，GitHub Actions 会把 `dist` 发布到 GitHub Pages。首次发布时，请在仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

## 技术栈

TypeScript · Vite · Phaser 3 · Matter.js · Vitest · vite-plugin-pwa
